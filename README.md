## Research Projects

### Sarcototivirus pseudocauda — Cryptic Virus Discovery
Computational virology project for MGY441 Bioinformatics (UofT Molecular Genetics). Mined public RNA-seq archives to identify a previously unreported virus-like sequence in bovine muscle transcriptomes, traced an apparent signal to poly-A false priming, and classified the sequence using phylogenetic and structural methods.

🔗 Report: https://github.com/khushikankaria/VIRUSxDISCVRY/blob/main/virus/Sarcototivirus_pseudocauda.md
